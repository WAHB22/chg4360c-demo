# Logos

One logo per place, named `<place>.png`, for example `bobino.png`. It appears on the sign plate of that place. Until a file is present the plate stays empty with a faint label.

* Transparent PNG, at least 512 px on the long side.
* Only logos Wahb has confirmed may be used. No real logos go here until he says yes, and the university crest stays out until he confirms.

This folder is part of the public deployment, so nothing private goes here.
