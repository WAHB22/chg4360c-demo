# DESIGN.md library

Copied from https://github.com/VoltAgent/awesome-design-md (commit f696123, 2026-09-21), MIT license (see LICENSE).

Each folder holds a DESIGN.md: a plain-text design system (tokens, type, color, components, rules) that an AI agent can follow.
To use one, point Claude at it, e.g. "build this page following design-md/claude/DESIGN.md", or copy it to the project root as DESIGN.md.
