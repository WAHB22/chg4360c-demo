# Characters

ICON and the seven core bots are drawn in code (`public/js/characters.js`), from the data in `public/js/bots.js`. Painted art can be added here later, one file per character: `icon.webp`, `scholar.webp`, `scout.webp`, `baker.webp`, `keeper.webp`, `steward.webp`, `bard.webp`, `herald.webp`.

* Simple round bodies, dot eyes, one prop each, warm top light and a cool blue underside.
* ICON is slightly taller, in a long cream traveller coat with gold trim, a satchel of scrolls and a compass emblem.
* Transparent background, at least 512 px tall, the feet on the bottom edge.

Only original artwork goes here, nothing from any show. This folder is part of the public deployment.
